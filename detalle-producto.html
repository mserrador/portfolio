Diseño Responsive para E-Commerce

Desarrollo de una interfaz de usuario (UI) para una ficha de producto de una tienda online. El foco principal de este proyecto es la Adaptabilidad (Responsive Design).

Se ha utilizado una combinación de CSS Grid para la estructura general y Flexbox para los componentes internos, asegurando que la página se visualice perfectamente tanto en dispositivos móviles como en pantallas de escritorio grandes.
