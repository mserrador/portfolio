Calendario de Adviento

Este proyecto es un calendario de adviento interactivo desarrollado en 2026. La característica principal es el diseño gráfico personalizado: todas las ilustraciones vectoriales (SVG) han sido diseñadas y creadas por mí, dándole un estilo único.

Utiliza JavaScript para gestionar la lógica de fechas y CSS Grid para la estructura responsive.
