Animación Avanzada con CSS

Este proyecto explora las capacidades de animación nativas de CSS3 sin utilizar JavaScript. El objetivo era crear una escena dinámica y fluida utilizando únicamente código de estilos.

Se implementan @keyframes complejos para simular el movimiento del barco sobre el agua, jugando con propiedades como transform: translate y rotate para dar una sensación de oleaje realista y bucles infinitos.
